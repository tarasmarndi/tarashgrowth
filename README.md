# Performance Marketing Portfolio

A simple personal portfolio website built with HTML, CSS and JavaScript and hosted using GitHub Pages.

## Customise before publishing
1. Update the introduction and About section in `index.html`.
2. Replace the example case studies with projects you actually worked on.
3. Replace `YOUR_EMAIL@example.com`, `YOUR-LINKEDIN` and `YOUR-GITHUB-USERNAME`.
4. Add approved images to the `assets/` folder and reference them from `index.html`.
5. Remove any skill or tool you cannot confidently explain in an interview.

## Publish with GitHub Pages
1. Create a GitHub repository named `YOUR-GITHUB-USERNAME.github.io`.
2. Upload `index.html`, `style.css`, `script.js`, `README.md` and the `assets` folder to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select **main** and **/(root)**, then click **Save**.
6. Wait for GitHub Pages to publish. Your site will be at `https://YOUR-GITHUB-USERNAME.github.io/`.

## Confidentiality
Do not publish client names, personal information, account IDs, screenshots, budgets or performance results without permission. Use anonymised examples and clearly label illustrative or undisclosed results. Never invent campaign outcomes.
